# Constelly

Daily dot-to-dot constellation puzzle — constelly.com. Static site: HTML + CSS + vanilla JS,
no backend. See `CLAUDE.md` for the full design.

## Layout
```
index.html              page shell
css/style.css           theme + layout
js/main.js              entry point, wires modules together
js/daily.js             UTC day index → today's puzzle (LAUNCH_DATE_UTC lives here)
js/game.js              pure game rules (degrees, hard cap, dot status, win, undo, hints)
js/render.js            SVG drawing
js/input.js             tap-tap + drag + eraser via pointer events
js/storage.js           localStorage progress / history / streak
js/share.js             spoiler-free share text
js/strings.js           all player-facing copy for results / share / how-to-play / stats
js/format.js            time + countdown formatting
tests/*.test.mjs        node --test unit tests for the pure modules
puzzles/puzzles.json    all puzzles, one object each (generated by tools/author_puzzles.py)
puzzles/samples.json    old test puzzles, not loaded by the game
puzzles/schema.json     JSON Schema for the puzzle file
tools/validate_puzzles.py  pre-publish checks
tools/author_puzzles.py    puzzle drawings (source of truth) -> puzzles.json
tools/preview_puzzles.py   contact-sheet PNG of all puzzles (matplotlib)
tools/puzzle_quality.py    flags dull puzzles (long chains of degree-2 dots)
tools/make_tutorial_gif.py regenerates img/tutorial.gif + tutorial-still.png (cairosvg, pillow)
img/                       tutorial animation for the how-to-play dialog
privacy.html               privacy notice (draft)
.nojekyll               tells GitHub Pages to serve files as-is
```

## Run locally
ES modules and `fetch()` don't work from `file://`, so serve the folder:
```
python -m http.server 8000
```
then open http://localhost:8000. (Or use VS Code's Live Server extension.)
On localhost, `?p=N` opens `puzzles[N]` instead of today's puzzle.

## Tests
Zero-dependency unit tests for the pure modules (Node 22+, built-in runner, no `npm install`):
```
node --test
```
This finds `tests/*.test.mjs` automatically.

## Validate puzzles
Run before publishing any change to `puzzles/puzzles.json` (exits 1 on problems):
```
python tools/validate_puzzles.py
```
`pip install jsonschema` (3.x or 4.x) enables the full schema check; without it a minimal
shape check runs. Coordinates: `x` 0–1, `y` 0–4/3 (portrait 3:4 board); the validator also checks
dot spacing (≥ 0.11), edge margin (≥ 0.05) and that no dot sits on a line it isn't part of.

## Deploy (GitHub Pages)
Push to GitHub → repo Settings → Pages → Deploy from branch `main`, folder `/ (root)`.
Custom domain: add a `CNAME` file containing `constelly.com` **after** the domain is bought
and DNS is pointed at GitHub.
