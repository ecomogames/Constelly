Constelly editor

This editor only works on your own computer. From the project folder run:

python tools/editor.py

It opens this page at http://127.0.0.1:8001/tools/editor.html with the local server that reads and writes the puzzles.

Constelly editor

    Paint
    Click: add a dot, joined to the selected one (on a line: splits it) · Click a dot: select it, or join / unjoin it with the selected one · Drag: move · Right-click: delete a dot or line · Del: delete selected · Esc: deselect · Ctrl+Z: undo · Ctrl+S: save · Paint: pick a colour, click or drag over lines (Esc stops)
